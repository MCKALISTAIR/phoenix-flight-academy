# Generative Media & Visual Asset Skill

## When to Use
Apply when writing prompts or generating visual assets, UI illustrations, or reference images to guarantee high-fidelity, coherent aesthetic output.

## Guidelines
- **Prompt Structure**: Subject + Medium/Lighting + Composition + Detail/Texture + Color Palette.
- **UI Mockup Isolation**: When prompting UI screens, explicitly specify "clean interface, no surrounding device frames, flat perspective, crisp typography".
- **Aviation Authenticity**: Use accurate aviation terminology (e.g., "high-wing single-engine trainer aircraft, runway touchdown zone markings, dusk golden hour lighting, sharp cockpit instruments").
- **Consistency**: Lock camera angle, aspect ratio (`16:9` for scenery, `1:1` for badges), and color grading across related assets.
