# PowerPoint (.pptx) Skill

## When to Use

Use when generating presentation slide decks or briefing materials.

## Tooling & Patterns

- **Node.js / TypeScript**: Use `pptxgenjs` (`npm install pptxgenjs`) for programmatic deck generation.
- **Python**: Use `python-pptx` (`pip install python-pptx`) to read, modify, and build slides.
- **Slide Layout Discipline**:
  - Keep 1 core idea per slide.
  - Generous margins, strong typographic contrast between slide titles and bullets.
  - Use tables and structured cards over endless unformatted bullet lists.
